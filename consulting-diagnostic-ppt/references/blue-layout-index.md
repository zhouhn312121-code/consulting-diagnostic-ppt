# 蓝色系列模版页型索引

页型索引依据 101 页的《蓝色系列模版PPT.pptx》编制。持有对应模板时，可在任务中上传，或把它放在技能目录内的 `assets/blue-series-template.pptx`。使用其他模板时，按逻辑类型和容量选页。全套 101 页，16:9。第 1–2 页为封面和目录，第 3–88 页为正文范例，第 89–95 页为甘特及图表组件，第 96–101 页为图标库。页码按原文件顺序。

使用对应的蓝色模板时，按内容关系、分支或阶段数、字量和需要保留的证据形式选页。明确给出原页码时，使用指定页。无完全匹配时，说明采用哪一页、将调整哪些槽位。填充时用本次提供的事实、数字和文字。以用户指定的视觉模板为准。未指定时可用咨询交付的基础配色。主蓝 #0066BC、深蓝 #1845BA、浅蓝 #DEEBFA 和 #9FBFF1、标题深蓝 #23285B。问题和改进状态色遵循风格指南。沿用模板形状时逐项检查标题、色块、线条和表头，保留颜色承担的风险、状态和对比含义。

容量是根据页面布局给出的近似填充量。对象栏只列原页含有的图片、原生表格和原生图表。数字不表示全部对象类型，图片中的图案、文字和数字需按实际对象核验。最终填充后按标题长度、文本量和可编辑性检查成品。
